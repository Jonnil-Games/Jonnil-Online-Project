# Jonnil Online source

This repository contains selected GML scripts, object events, and their GameMaker resource definitions from Jonnil Online.

## What is included

- `JonnilOnline/scripts/`: game scripts and their resource definitions.
- `JonnilOnline/objects/`: object events and their resource definitions.
- The license and its scope.

## Working with the code

This is a code-only snapshot. It is not a complete GameMaker project and cannot be built on its own. Project registrations, rooms, sprites, fonts, included files, and extensions are not included. Those dependencies must be supplied under suitable terms before building a working project.

The private development repository, its history, and internal `docs/` are not included. Future snapshots use the same inclusion policy.

The networking code contains public service addresses. Use your own server addresses and credentials for independent hosting. Do not include real administrator credentials in source or remove the official-server credential boundary to make a test work.

Excluding content from this repository does not establish rights to distribute that content in game builds.
